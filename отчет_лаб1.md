# Корниенко Андрей ИТ-9 Лабораторная №1

# Задание 1

## Задача 1
### Текст задачи
Дробная часть. Напишите метод fraction(double x), который принимает вещественное число x и возвращает его дробную часть.
### Алгоритм решения
Преобразуем x в целое число, тем самым убирая его дробную часть. Затем вычитаем это значение из исходного числа.

## Задача 2
### Текст задачи
Сумма знаков. Напишите метод sumLastNums(int x), который принимает целое число x и возвращает сумму двух его последних цифр.
### Алгоритм решения
Сначала используем абсолютное значение числа. Последнюю цифру находим выражением x % 10, предпоследнюю — выражением (x / 10) % 10. Складываем найденные цифры и возвращаем результат.

## Задача 3
### Текст задачи
Букву в число. Напишите метод charToNum(char x), который принимает символ-цифру '0'-'9' и возвращает соответствующее ей целое число.
### Алгоритм решения
Из кода символа x вычитаем код символа '0'. Полученная разность соответствует числу, записанному этим символом.

## Задача 4
### Текст задачи
Есть ли позитив. Напишите метод isPositive(int x), который возвращает true, если число x строго больше 0, и false в противном случае.
### Алгоритм решения
Сравниваем x с нулём. Результат проверки x > 0 и будет возвращаемым логическим значением.

## Задача 5
### Текст задачи
Двузначное. Напишите метод is2Digits(int x), который возвращает true, если число x является двузначным.
### Алгоритм решения
Определяем абсолютное значение x, затем проверяем, находится ли оно в пределах от 10 до 99 включительно.


# Задание 2

## Задача 1
### Текст задачи
Модуль числа. Напишите метод abs(int x), который возвращает абсолютное значение (модуль) числа x.
### Алгоритм решения
Проверяем знак числа: для отрицательного x возвращаем противоположное значение, а для нуля и положительных чисел — само x.

## Задача 2
### Текст задачи
Безопасное деление. Напишите метод safeDiv(int x, int y), который делит x на y. Если y равен 0, метод должен возвращать 0.
### Алгоритм решения
Вначале выясняем, равен ли делитель нулю. В этом случае результатом будет 0; в остальных случаях делим x на y, предварительно преобразовав x к типу double.

## Задача 3
### Текст задачи
Тридцать пять. Напишите метод is35(int x), который возвращает true, если число x делится нацело на 3 или на 5, но НЕ на оба одновременно.
### Алгоритм решения
Отдельно определяем, делится ли число на 3 и на 5 без остатка. Возвращаем true, когда верно только одно из этих условий, и false в остальных случаях.

## Задача 4
### Текст задачи
Строка сравнения. Напишите метод makeDecision(int x, int y), который сравнивает x и y и возвращает строку вида "x > y", "x < y" или "x == y".
### Алгоритм решения
Сравниваем два числа по очереди: сначала проверяем, больше ли x числа y, затем меньше ли. Если они равны, формируем строку с оператором равенства.

## Задача 5
### Текст задачи
Тройной максимум. Напишите метод max3(int x, int y, int z), который возвращает наибольшее из трех чисел.
### Алгоритм решения
Сначала считаем x наибольшим числом. Затем сравниваем с ним y и z, заменяя сохранённый максимум при обнаружении большего значения. В конце возвращаем найденный максимум.


# Задание 3

## Задача 1
### Текст задачи
Числа подряд. Напишите метод listNums(int x), который возвращает строку со всеми целыми числами от 0 до x включительно через пробел.
### Алгоритм решения
Организуем цикл от 0 до x включительно. На каждом шаге дописываем текущее значение счётчика и пробел в результирующую строку.

## Задача 2
### Текст задачи
Числа наоборот. Напишите метод reverseListNums(int x), который возвращает строку со всеми целыми числами от x до 0 включительно через пробел.
### Алгоритм решения
Перебираем числа в обратном порядке: начинаем с x и уменьшаем счётчик до нуля. Каждое значение добавляем в строку вместе с пробелом.

## Задача 3
### Текст задачи
Четные числа. Напишите метод chet(int x), который возвращает строку со всеми четными числами от 0 до x включительно через пробел.
### Алгоритм решения
Начинаем перебор с нуля и увеличиваем счётчик на 2, пока он не превысит x. Так в строку попадают только чётные числа.

## Задача 4
### Текст задачи
Степень числа. Напишите метод pow(int x, int y), который возводит x в степень y (y >= 0) без использования Math.pow.
### Алгоритм решения
Задаём начальное значение результата равным 1. Затем y раз умножаем его на x, после чего возвращаем полученное значение.

## Задача 5
### Текст задачи
Длина числа. Напишите метод numLen(long x), который возвращает количество цифр в числе x.
### Алгоритм решения
Для нуля сразу возвращаем 1, поскольку в нём одна цифра. В остальных случаях берём модуль числа и последовательно делим его на 10, считая количество выполненных делений до достижения нуля.


# Задание 4

## Задача 1
### Текст задачи
Поиск первого значения. Напишите метод findFirst(int[] arr, int x), который возвращает индекс первого вхождения числа x в массив arr (или -1, если не найдено).
### Алгоритм решения
Перебираем элементы массива от начала к концу. Как только встречаем x, возвращаем позицию найденного элемента. Если совпадений нет, результатом будет -1.

## Задача 2
### Текст задачи
Поиск последнего значения. Напишите метод findLast(int[] arr, int x), который возвращает индекс последнего вхождения числа x в массив arr (или -1, если не найдено).
### Алгоритм решения
Начинаем поиск с последнего элемента и движемся к первому. При обнаружении значения x возвращаем его индекс; если элемент не найден, возвращаем -1.

## Задача 3
### Текст задачи
Поиск максимального по модулю. Напишите метод maxAbs(int[] arr), который возвращает элемент массива, наибольший по абсолютному значению.
### Алгоритм решения
В качестве начального максимума выбираем первый элемент массива. Далее сравниваем абсолютные значения остальных элементов с текущим максимумом и при необходимости заменяем его. Возвращаем сам элемент, модуль которого оказался наибольшим.

## Задача 4
### Текст задачи
Добавление в массив. Напишите метод add(int[] arr, int x, int pos), который вставляет элемент x в массив arr по индексу pos.
### Алгоритм решения
Выделяем массив на один элемент длиннее исходного. Сначала переносим элементы, расположенные перед pos, затем помещаем x в указанную позицию, а оставшиеся значения копируем со сдвигом вправо на одну ячейку.

## Задача 5
### Текст задачи
Добавление массива в массив. Напишите метод add(int[] arr, int[] ins, int pos), который вставляет массив ins в массив arr начиная с позиции pos.
### Алгоритм решения
Создаём новый массив, размер которого равен сумме длин arr и ins. Заполняем его по порядку: копируем часть arr до pos, размещаем на её месте все элементы ins, после чего добавляем оставшуюся часть arr.
